# Псевдоразметка старой YOLO

Создана на ноутбуке 03.11.2026: `data/pseudo_teacher_v1`.
Итого 76 кадров и 521 рамка. По видео: 25_12-20 — 24, 25_2-10 — 2,
26_12-20 — 44, 43_15 — 5, 49_5 — 1. Все пять folds непустые и не пересекаются
по видео, однако folds с 1–2 кадрами слишком малы для устойчивой оценки.
Проверены существование файлов, число/границы рамок, разбиения; визуально
просмотрена контактная таблица `preview.jpg`, не каждый отдельный ценник.
Полная ручная проверка псевдометок не проводилась.

Запуск существующего обучения на этом снимке:

```bash
poetry run price-scanner train oof=yolo dataset=data/pseudo_teacher_v1 pull_dvc=false output=runs/yolo_pseudo_v1
```

Параметры эпох нужно задать отдельно: прежние три эпохи с нуля не дали
пригодного детектора. В этом шаге обучение не запускалось.

```powershell
$env:YOLO_CONFIG_DIR = "$PWD/data/pseudo_runtime"
python -m lenta_price_tag_scanner.pseudo_labels
```

Используется исходный base_pipeline/price_tag.pt, а не новые трёхэпоховые
fold-модели. Видео читаются последовательно, кадры отбираются раз в секунду
по реальным PTS. CSV не определяют время отбора и не изменяются.

Детекции ищутся от confidence 0.25. Кадр включается только если все найденные
кандидаты имеют confidence >= 0.7 и проходят пороги размера, резкости,
контраста и экспозиции. При сомнительной рамке исключается весь кадр:
удаление только этой рамки ошибочно превратило бы видимый объект в фон.
Кадры без детекций не включаются как достоверные отрицательные примеры.
Не обнаруженные учителем объекты всё равно возможны; ручной проверки пока нет.

Артефакты: yolo/images и yolo/labels в YOLO-формате, yolo/manifest.json с временем и оценками,
audit.jsonl с причинами исключения, yolo/folds.json с разбиением по целым видео,
summary.json с SHA256 учителя. Статус reviewed=false, source=teacher_pseudo.
Не использовать эти метки как независимый эталон правильности распознавания
цен/названий. Заявленное пользователем mAP ~0.88 не перепроверялось.

Пять folds охватывают пять исходных видео; usable=false означает, что после
фильтрации train или validation пусты и такой fold нельзя обучать автоматически.
История обучения учителя неизвестна, поэтому независимость от него не заявляется.
