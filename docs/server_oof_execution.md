## Одноразовое ожидание

Запущен процесс `lenta_price_tag_scanner.resource_queue`:

- только физическая GPU0, `CUDA_VISIBLE_DEVICES=0`; GPU1 не используется;
- опрос раз в 30 секунд, три подряд проверки отсутствия compute-процессов,
  VRAM <=512 MiB, загрузка <=5%, свободно >=12 GiB;
- ожидание ограничено шестью часами;
- после допуска запускается `scripts/server/launch_oof.sh --execute`;
- после ошибки эксперимент автоматически не повторяется;
- при свободном диске <2 GiB во время работы останавливается только созданная
  процессная группа этого запуска, чужие процессы не затрагиваются.

GPU0 освободилась и прошла три проверки. Основной запуск начался:
очередь PID 505489, runner PID 516702, процесс обучения PID 516784.
