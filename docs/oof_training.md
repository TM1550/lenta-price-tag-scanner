# Датасеты и обучение по видео

Новый набор SAM3/Roboflow на 391 кадр и 2593 bbox, разделённый на 5 folds,
описан в [актуальной инструкции](yolo_roboflow_oof.md). Используйте команду
`price-scanner train-yolo` для него. Ниже сохранено описание первоначальных
наборов и прежних запусков; их 4-fold разбиение YOLO к новому набору не относится.

YOLO использует исходную разметку пользователя из Roboflow (CC BY 4.0), а EfficientNet — псевдометки ранее обученного классификатора. Сомнительные кропы исключены. Метки EfficientNet: 0 — отрицательное предложение учителя, 1 — положительное. Они не подтверждают пригодность для OCR без ручной проверки.

Исходные train/valid/test YOLO объединяются и перегруппируются по видео из имени файла. Имена с префиксом Unlabeled тоже имеют файлы аннотаций и обрабатываются по ним, а не по значению префикса. Совпадающие по SHA-256 изображения удаляются только при совпадении меток и группы; конфликты останавливают сборку. Координаты и читаемость изображений проверяются. Исходные файлы не изменяются.

Каждая модель использует свою карту групп из manifest.json. Одно видео целиком отложено, остальные входят в обучение. folds.json содержит переносимые пути относительно корня датасета. train_oof.py создаёт абсолютные списки и data.yaml в каталоге конкретного запуска, поэтому перенос датасета не требует редактирования его manifest. Исходный YAML Roboflow с неверными относительными путями не используется.

## Setup

Python 3.12, `poetry install`. Для RTX 5090 требуется совместимая CUDA-сборка PyTorch. Проверенное серверное окружение находится в ../.venv, точные версии — requirements-server.txt в комплекте результатов. poetry.lock обновлён отдельно; установка чистого окружения только из lock ещё не проверена.

## Train

Из корня проекта:

```bash
poetry run python -m lenta_price_tag_scanner.import_yolo
poetry run python -m lenta_price_tag_scanner.train_oof
poetry run python -m lenta_price_tag_scanner.train_oof oof=yolo output=runs/oof_yolo
```

Конфиги: configs/import_yolo.yaml, configs/train_oof.yaml, configs/oof/\*.yaml. Пути данных разрешаются относительно корня проекта. Для уже полученного комплекта датасета импорт повторять не нужно. Каталоги результатов должны быть новыми.

По умолчанию MLflow ожидается на http://127.0.0.1:8080. Для автономной проверки допустимо переопределить mlflow_uri на sqlite с абсолютным путём внутри своей рабочей области. CUDA_VISIBLE_DEVICES ограничивает доступный GPU. На общем сервере перед GPU-запуском проверить доступность ресурса; чужие процессы не останавливать.

```bash
poetry run python -m lenta_price_tag_scanner.train_oof smoke=true oof.size=64 oof.workers=0 output=runs/check_efficient
poetry run python -m lenta_price_tag_scanner.train_oof oof=yolo smoke=true oof.size=320 oof.workers=0 output=runs/check_yolo
```

Smoke использует до 8 обучающих и 8 отложенных примеров на fold и одну эпоху. Его метрики не являются оценкой качества. Полное обучение задаётся epochs в конфиге. Каждая модель инициализируется заново: YOLO из архитектуры YAML, EfficientNet с pretrained=false. Веса учителей не используются для инициализации. Это исключает прямое использование весов, уже видевших отложенное видео; для EfficientNet остаётся утечка через псевдометки.

EfficientNet обучается через Lightning, YOLO — через Ultralytics Trainer. Для EfficientNet RGB + ImageNet normalization, метка 1 соответствует sigmoid(logit); это отличается от legacy учителя BGR + 1-sigmoid. При использовании нового checkpoint соблюдать его metadata. Обучение идёт фиксированное число эпох; для оценки используется последняя модель, а не лучшая по outer fold. Подбор гиперпараметров по outer fold не выполнять.

MLflow записывает параметры, seed, commit (либо uncommitted), SHA-256 manifest, loss и итоговые метрики. В runs/<имя> сохраняются config, metrics.json, fold_N/oof_predictions.json, модели и графики plots. Для отчёта переносите графики выбранного полного эксперимента в корневой plots; тестовые графики явно помечайте smoke. YOLO пишет графики потерь и результаты своей оценки; EfficientNet — CSV истории train_loss и графики метрик по folds.

Это код подготовки данных и обучения. Он не завершает весь проект MLsys: полный прогон, ручная оценка EfficientNet, OCR/CSV, проверка production-export и serving остаются отдельными этапами. Оригинальный детектор может использоваться для подготовки кропов, но не для честной независимой OOF-оценки на видео, которые он уже видел.

## Итоговый комплект

YOLO: 251 изображение, 2118 рамок, 4 folds (25_12-20: 96; 26_12-20: 107; 26_2-10: 31; 43_15: 17). EfficientNet: 2127 изображений, 5 folds, 256 положительных и 1871 отрицательный пример. Сомнительные исключены. Полная проверка: python -m lenta_price_tag_scanner.validate_oof.

Данные отслеживаются data/oof_v2.dvc. Новый DVC remote для них не настроен: комплект передаётся архивом. После распаковки можно выполнить dvc add data/oof_v2 и dvc push после настройки своего remote. Не использовать старый data.dvc как описание нового датасета.

Проверки: black/isort/flake8 новых модулей, декодирование всех изображений, покрытие folds и отсутствие пересечений. EfficientNet: smoke 5 folds; YOLO: smoke 4 folds исходной разметки. Полное обучение, весь pre-commit репозитория и чистая установка из poetry.lock не выполнялись.
