# Переразметка EfficientNet

На ноутбуке готовые датасеты уже находятся в data/oof_v2: yolo (251 кадр, 4 folds) и efficient (2127 кропов, 5 folds). Исходные метки YOLO сохранены. Для ручной переразметки дополнительно переданы все 2699 кандидатов в data/efficient_review, включая 572 сомнительных.

labels.csv содержит пути к изображениям, исходное видео/fold, предложение и оценку учителя, а также пустую label, reviewed=false и comment. Папки positive/negative/review отражают только мнение учителя. Исходный source_manifest.jsonl не редактировать: он сохраняет происхождение и разбиение по видео.

Для каждого проверенного изображения:

- label=1: ценник пригоден для извлечения нужных полей текста;
- label=0: ложная детекция или непригодный кроп (обрезка, сильный смаз, перекрытие);
- reviewed=true: решение принято человеком;
- если решить нельзя — оставить reviewed=false, такой пример в обучение не попадёт.

Уточните для себя критерий читаемости: достаточно ли названия и цены или нужны также мелкие коды. Применяйте один критерий ко всем видео. Оценивать можно после поворота на 90 градусов против часовой стрелки; исходные файлы не поворачивать и не заменять без изменения preprocessing обучения.

После разметки:

```powershell
poetry run python -m lenta_price_tag_scanner.rebuild_efficient
poetry run python -m lenta_price_tag_scanner.train_oof dataset=data/efficient_reviewed output=runs/efficient_reviewed
```

Сборщик берёт только reviewed=true с label 0/1; требует примеры из всех пяти видео и оба класса в каждом обучающем partition. Копирует изображения в новый каталог data/efficient_reviewed/efficient, создаёт manifest/folds. Старый датасет не перезаписывается. Неизвестные/повторные пути и неправильные метки вызывают ошибку. Разбиение берётся из source_manifest, а не из вручную изменённого столбца fold CSV.

После завершения можно версионировать новый набор `dvc add data/efficient_reviewed`. Для этого нового набора использовать pull_dvc=false: старый флаг загрузки train пока привязан к data/oof_v2.dvc. Для честной оценки полезно разметить отложенные видео вручную независимо от teacher_suggestion; псевдометки не считать эталоном.

На момент последней проверки в прежнем data/oof_v2/efficient отсутствовали 112 файлов, перечисленных в manifest. Возможные ручные изменения сохранены. Полная независимая копия серверного набора находится в data/efficient_original (2127 изображений); для неё можно задать dataset=data/efficient_original. Новый набор для ручной проверки data/efficient_review содержит все 2699 кандидатов.
