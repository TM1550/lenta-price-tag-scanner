# Очистка экспорта SAM3 / Roboflow

В `price_tags.v1i.yolov8` находится экспорт 393 кадров из пакета 400 кадров.
Он содержит смешанные записи: YOLO bbox из пяти чисел и полигоны SAM3.
Для обучения детектора полигоны преобразуются в минимальные охватывающие
прямоугольники, параллельные осям изображения.

Запуск из корня репозитория:

```powershell
& ../.venv-pseudolabel/Scripts/python.exe -m lenta_price_tag_scanner.clean_yolo_labels
```

Результат: `data/yolo_roboflow_clean_v1`. Исходник остаётся без изменений,
существующий результат повторный запуск не перезаписывает. Другие пороги можно
задать через Hydra, например `iou_threshold=0.6 min_side_px=24 output=data/clean_v2`.

Порядок обработки:

1. Проверка соответствия изображений/меток, классов и координат. Проверка связи
   с манифестом исходных кадров и неизменности разрешения. Ошибочные записи
   останавливают обработку; они не превращаются в пустые метки.
2. Преобразование полигонов в bbox; обрезка границ bbox по изображению.
3. Удаление боксов с короткой стороной **меньше 16 пикселей** в исходном кадре
   3840×2160, включая вырожденные боксы. Ровно 16 пикселей допускается.
4. Class-aware greedy NMS с **IoU > 0,5**. В разметке нет confidence, поэтому
   приоритет задаётся площадью bbox по убыванию; при равенстве — номером строки.
   Удаляется бокс, сильно совпадающий с уже сохранённым боксом того же класса.
   Небольшое пересечение соседних ценников допустимо. Полностью вложенные боксы
   с низким IoU не удаляются отдельным правилом containment.

Это геометрический фильтр дубликатов, он не определяет, какая из двух разных
границ ценника правильнее. Сохранение большей площади помогает оставить полный
ценник вместо его фрагмента, но результат необходимо просмотреть.

Файлы результата:

- `train/images`, `train/labels`: неизменённые копии изображений и очищенные
  метки; каждая строка содержит только `class cx cy w h`.
- `review.html`: локальная галерея всех изменённых и пустых кадров. Флажок
  Show removed переключает отображение удалённых боксов. Зелёный — сохранённый,
  красный — удалённый NMS, жёлтый — слишком маленький.
- `previews`: 30 статических изображений с наибольшим числом удалений.
- `audit.json`: все сохранённые и удалённые bbox, номера исходных строк,
  причины удаления, IoU и строка сохранённого бокса для NMS.
- `manifest.json`: источник видео, время и fold, число объектов, хеши входных
  изображений/меток и выходных меток.
- `report.json`: суммарные результаты и список кадров исходного пакета,
  отсутствующих в экспорте Roboflow.
- `source_*`: исходные метаданные Roboflow, включая лицензию.
- `COMPLETE.txt`: маркер успешного завершения.

Пустые изображения сохраняются и явно отмечаются в манифесте. Перед обучением
нужно подтвердить отсутствие подходящих объектов или исключить эти кадры:
автоматическое удаление мелких меток не доказывает, что кадр является фоном.
Фильтр размера задаёт целевой масштаб объектов; оценивать детектор следует с
учётом того же правила. Мелкие реальные ценники после удаления меток будут
неразмеченными объектами, поэтому порог выбран консервативно.

Случайное разбиение не создаётся. В экспорте есть только `train`, поэтому
`data.yaml` очищенного набора не содержит фиктивных `val/test`. Для OOF нужно
собрать пять train/val-конфигураций по полю `video`/`fold` манифеста после
визуальной проверки. Данные находятся под игнорируемой Git папкой `data`.

## Выполненный запуск

Из 2655 исходных объектов сохранено **2593 bbox** на **393 изображениях**.
Удалены 60 объектов с короткой стороной 1–13 px и 2 bbox с IoU выше 0,5.
2457 исходных полигонов преобразованы в прямоугольники; ещё 198 записей уже
были bbox. Минимальная короткая сторона сохранённых боксов — 17 px,
максимальный IoU пары сохранённых боксов — 0,489011.

Два кадра с пустыми метками были пустыми ещё до очистки; новых пустых кадров
фильтр не создал. Семь кадров исходного пакета не вошли в экспорт Roboflow,
их имена перечислены в `report.json`.

Проверены SHA256 всех исходных и скопированных изображений, исходных и выходных
меток; исходные файлы не изменились. Все выходные строки соответствуют формату
детекции, удовлетворяют фильтру размера и NMS. Результаты проверки сохранены
в `verification.json`. Шесть проверок геометрии и NMS прошли успешно.
