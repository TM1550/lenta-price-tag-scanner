## Зафиксированная оценка

Пять YOLO обучены по 100 эпох с разделением по видео; используется `last.pt`.
Полный pipeline с PaddleOCR + Qwen3-VL и выключенным EfficientNet получил
**154/3701 = 4.1610%** правильных полей, macro 4.3896%. Автоматическое связывание
принято пользователем. Исторический результат сохранён.
05.11.2026 завершён [новый полный прогон с EfficientNet rank](efficient_video_oof_results.md):
152/3701 = 4.1070%, macro 4.3018%. Для каждого видео использованы checkpoint
соответствующих YOLO- и EfficientNet-folds; повторное обучение не выполнялось.

Это согласованная метрика проекта, отличающаяся от официальной метрики хакатона.
В историческом прогоне без EfficientNet связано 95/274 GT-строк; временные ошибки и фрагментация треков ограничивают
результат. Эти факты описаны как ограничения, а не как обязательство улучшения.

## Отличия от первоначальной заявки

CSV имеет 29 колонок за счёт дополнительных QR-полей. Основной OCR —
PaddleOCR + Qwen3-VL, EasyOCR сохранён как baseline. Qwen является VLM.
Каталог содержит `fullname` и `code`, поэтому не восстанавливает большинство
ценовых полей. Строка CSV соответствует сегменту трека, а не гарантированно
уникальному физическому ценнику. EfficientNet поддерживает rank/filter/off;
новый режим rank не выдаётся за источник исторической OOF-метрики.

## Передача проекта

Код опубликован в `TM1550/lenta-price-tag-scanner`, подготовленные данные и модели
хранятся в MinIO. Локальный резервный архив исключён из целей DVC.
Порядок подключения описан в [инструкции DVC](dvc_handoff.md).

Для проверки доступен публичный бакет `lenta-dvc-release` только для чтения.
Скачивание выполняется напрямую через HTTPS без SSH-доступа. При приёмке на его машине выполняется последовательность
clone → install → DVC pull → короткий infer. Повторное скачивание всех артефактов
после миграции не запускалось; завершение передачи подтверждено успешным DVC push.

05.11.2026 дополнительно проверено наличие объектов всех девяти наборов по HTTPS
с аккаунтом только для чтения: MD5 девяти directory-manifests совпадают, все
6836 ссылок на файлы найдены в хранилище, пропусков нет. Проверка скачала только
метаданные. Прямой DVC pull одного файла в пустой cache также завершился успешно;
полное восстановление девяти наборов этим не заявляется.

При аудите обнаружено, что правило `/data/*` заставляло DVC/Dulwich пропускать
каталог `data/` при автоматическом поиске. Оно заменено на `/data/?*`: DVC
обнаруживает девять целей, содержимое наборов остаётся игнорируемым Git.

## Закрытие замечаний аудита 05.11.2026

Замечания предыдущего аудита устранены:

1. Серверный `evaluate_efficient_oof.py` переведён с argparse на Click.
   Сохранены именованные опции и режим `--prepare-only`; Hydra overrides
   передаются завершающими аргументами `KEY=VALUE`.
2. Загрузка runner в тестах выполняется в `setUpClass`, а не на уровне модуля.
3. Ресурсные параметры перенесены в `configs/evaluate_efficient_oof.yaml`,
   вес ранжирования наследуется из видеопайплайна. Фиксированные GPU0 и единица
   GiB представлены именованными константами. Итоговый конфиг сохраняется
   вместе с результатом. Ограничение использования только GPU0 сохранено.
4. Проектное предложение в Markdown и PDF синхронизировано с текущими DVC,
   названием репозитория, измеренным EfficientNet rank OOF и результатами
   инженерных проверок. Ссылки размещены в соответствующих разделах.
5. Исправлен автоматический поиск девяти DVC-целей через правило `.gitignore`.
   Содержимое наборов и локальные ключи продолжают игнорироваться Git.

Текущая проверка включает 61 unit-тест и восемь pre-commit hooks. Дополнительные
тесты покрывают передачу Hydra-настроек в пять подготовленных folds, отказ
при некорректных ресурсах, отсутствие GPU-запросов в режиме подготовки и
ограничение запросов физической GPU0. Полное обучение и GPU-OOF в рамках
исправления оформления повторно не выполнялись; сохранённые метрики относятся
к версиям исходников, указанным в их протоколах.

Обязательные разделы задания реализованы и проверены в описанном объёме.
Протоколы обучения, сборки, CPU-инференса и deployment приведены выше.
Первичная загрузка публичного выпуска требует доступа к HTTPS endpoint.

Улучшение метрики, TensorRT и Triton
