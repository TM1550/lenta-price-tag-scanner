## Зафиксированная оценка

Пять YOLO обучены по 100 эпох с разделением по видео; используется `last.pt`.
Полный pipeline с PaddleOCR + Qwen3-VL и выключенным EfficientNet получил
**154/3701 = 4.1610%** правильных полей, macro 4.3896%. Автоматическое связывание
принято пользователем. Исторический результат сохранён.
05.11.2026 завершён [новый полный прогон с EfficientNet rank](efficient_video_oof_results.md):
152/3701 = 4.1070%, macro 4.3018%. Для каждого видео использованы checkpoint
соответствующих YOLO- и EfficientNet-folds; повторное обучение не выполнялось.

Это согласованная метрика проекта, отличающаяся от официальной метрики хакатона.
В историческом прогоне без EfficientNet связано 95/274 GT-строк; временные ошибки и фрагментация треков ограничивают
результат. Эти факты описаны как ограничения, а не как обязательство улучшения.

## Отличия от первоначальной заявки

CSV имеет 29 колонок за счёт дополнительных QR-полей. Основной OCR —
PaddleOCR + Qwen3-VL, EasyOCR сохранён как baseline. Qwen является VLM.
Каталог содержит `fullname` и `code`, поэтому не восстанавливает большинство
ценовых полей. Строка CSV соответствует сегменту трека, а не гарантированно
уникальному физическому ценнику. EfficientNet поддерживает rank/filter/off;
новый режим rank не выдаётся за источник исторической OOF-метрики.

## Передача проекта

Код опубликован в `TM1550/lenta-price-tag-scanner`, подготовленные данные и модели
хранятся в MinIO. Локальный резервный архив исключён из целей DVC.
Порядок подключения описан в [инструкции DVC](dvc_handoff.md).

Проверяющему предоставляются S3-ключи аккаунта только для чтения и SSH-доступ
для туннеля. При приёмке на его машине выполняется последовательность
clone → install → DVC pull → короткий infer. Повторное скачивание всех артефактов
после миграции не запускалось; завершение передачи подтверждено успешным DVC push.

Исторические аудиты в `project_audit.md`, `check_20261102.md` и старых протоколах
относятся к состоянию на дату проверки. Они не являются текущим списком пробелов.
Старые MLflow runs с `commit=uncommitted` подтверждены SHA256-описью исходников;
контрольное обучение демонстрирует корректное логирование новой версии кода.
