## Соответствие первоначальной заявке

- YOLO: 4 folds по четырём исходным видео, а не 5; изменение согласовано пользователем.
- EfficientNet: 5 folds. После ручной переразметки используется отдельный снимок
  2008 кропов (350 положительных, 1658 отрицательных). Два конфликтных ключа исключены.
- Пул OOF EfficientNet: precision 0.864486, recall 0.528571, F1 0.656028.
  Из-за потери пригодных ценников этот фильтр по умолчанию отключён.
- Сравнены 8 OCR-вариантов на 294 парах. Qwen3-VL baseline: CER 0.586948,
  WER 0.726145; лучшие по CER/WER варианты различаются. Подбор на этом же наборе
  не является независимой итоговой оценкой. В разметке есть усечённые строки.
- Основной вариант: YOLO → BoT-SORT/ограниченные сегменты → фильтры качества →
  PaddleOCR CPU + Qwen3-VL → QR/EAN и точное сопоставление каталога → CSV.
  Каталог помогает только при найденном коде; восстановление большинства полей
  через базу, предполагавшееся в заявке, пока не реализовано и не подтверждено.
- Итог на пяти видео: 430 строк, 916/9890 заполненных полей = 9.26188%.
  Без VLM на тех же кропах: 730 полей = 7.38119%. Это coverage, не доля правильно
  распознанных полей. Цель >0.04 по корректным полям требует полной эталонной
  таблицы и сопоставления ценников; сейчас цель нельзя считать достигнутой.
- Строка соответствует сегменту трека, а не гарантированно уникальному ценнику.
  Итоговая схема содержит 29 столбцов (18 основных и 11 дополнительных), что
  нужно учитывать при сравнении с первоначальной 18-полевой постановкой.

## Перед отправкой преподавателю

1. **Заменить пароль DVC, ранее находившийся в отслеживаемом .dvc/config.**
   В рабочем дереве секреты перенесены в игнорируемый .dvc/config.local.
   Проверить и очистить историю перед публикацией: изменение текущего файла
   не удаляет пароль из предыдущих коммитов. История автоматически не переписывалась.
2. Разместить coursework_artifacts.tar.gz или настроить доступный проверяющему
   DVC remote. Не публиковать config.local и личные учётные данные.
3. Проверить права распространения исходных видео и каталога, затем сделать
   репозиторий доступным, проверить main и имя; выполнить CI после push.
4. Для доказательства бизнес-метрики подготовить эталонные поля/сопоставления
   на независимых видео. Заполненность и OCR CER не заменяют эту оценку.
5. При необходимости согласовать с преподавателем раскрытые изменения заявки.
