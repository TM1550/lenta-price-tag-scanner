# Безопасная отправка на GitHub

Коммит подготовлен локально. Автоматической отправки на GitHub не выполнялось.
Перед отправкой замените ранее раскрытый пароль и согласуйте переписывание
main с сокомандником. Убедитесь, что `origin` указывает на нужный репозиторий.

PowerShell, из корня проекта:

```powershell
git status --short
git remote -v

$remoteLines = @(git ls-remote --heads origin refs/heads/main)
if ($LASTEXITCODE -ne 0) { throw 'Не удалось проверить origin/main. Отправка отменена.' }
$remoteHead = if ($remoteLines.Count) { ($remoteLines[0] -split '\s+')[0] } else { '' }
$knownOldHead = '3a0541f2c8056587d44e98a873b8f7e0d74a65a1'
if ($remoteHead -and $remoteHead -ne $knownOldHead) {
    throw 'Удалённая main отличается от известной старой истории. Сначала проверьте изменения сокомандника.'
}
git push "--force-with-lease=refs/heads/main:$remoteHead" origin HEAD:refs/heads/main
if ($LASTEXITCODE -ne 0) { throw 'Push отклонён. Не заменяйте команду на --force.' }
```

Команда разрешает замену только известной старой main либо создание отсутствующей
ветки. Если кто-то обновит main после проверки, lease отклонит отправку. При другом
SHA не подставляйте его автоматически: сначала убедитесь, что изменения коллеги
сохранены и согласованы. Не сливайте обратно историю с секретом.
Если защищённая ветка запрещает переписывание, согласуйте действия с владельцем.

`git push` отправит код и `.dvc`-указатели, но не датасеты и модели.
Для воспроизводимости сокоманднику/преподавателю нужен доступ к DVC remote:
[инструкция переноса в командное хранилище](dvc_handoff.md).
Локальный `laptop-temp` доступен только на этом ноутбуке.
