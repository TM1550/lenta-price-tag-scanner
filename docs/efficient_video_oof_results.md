## Модели и параметры

- Использованы прежние пять YOLO `last.pt` после 100 эпох, без переобучения.
  Проверены SHA256 checkpoint и фактического train-списка каждого fold.
- Для каждого видео загружен соответствующий EfficientNet-B0 fold после 10 эпох.
  Его held-out предсказания совпадают с текущим снимком 2008 изображений по
  именам, SHA256 и меткам. Списки train-видео восстановлены по исходному
  детерминированному разбиению; старые checkpoints не содержат train-manifest.
- `efficient_mode=rank`, `efficient_rank_weight=0.5`, `top_k=2`, `stride=3`,
  `imgsz=1280`, полные видео, `resume_tracks=null`. Классификатор влияет на
  ранжирование и не отбрасывает кропы по порогу вероятности.
- PaddleOCR работает на CPU, YOLO и Qwen — только на физической GPU0.
  Перед запуском подтверждены 120 секунд простоя, минимум 16 ГиБ свободной VRAM
  и 12 ГиБ диска. При занятости GPU0 перед следующим fold runner останавливается.
  GPU1 скрыта переменной `CUDA_VISIBLE_DEVICES=0`; чужие процессы не изменяются.

EfficientNet реально оценил **9561 кроп**.
После каждого видео проверены хеши обоих использованных checkpoint и режим `rank`.
Код запуска: `f292edf2c38d512fd72c2b1b81713a0863b88eca`; манифест исходников и весов сохранён.
Используется актуальная версия исходников проекта; сравнение с историческим
запуском не является строгой изоляцией эффекта одного изменения кода.

Счётчики независимо пересчитаны из пяти `field_comparison.csv` и совпадают с
итоговым JSON. Метрика измеряет правильность значений, а не заполненность.
Не найденные соответствия остаются в знаменателе. Связи не проверены вручную;
результат является согласованной метрикой проекта, а не официальным scorer хакатона.

export CUDA_VISIBLE_DEVICES=0

"$LENTA_WORKSPACE/.venv/bin/python" scripts/server/evaluate_efficient_oof.py \
  --baseline "$LENTA_WORKSPACE/results/video_oof_v1" \
  --efficient-assets "$run/efficient" \
  --output "$run/results_repeat_01" \
  --source-commit f292edf2c38d512fd72c2b1b81713a0863b88eca

Для подготовки конфигов без GPU-инференса добавляется `--prepare-only`.

PaddleOCR-веса, Qwen и пять EfficientNet-checkpoints. Для нового прогона
задаётся отдельная выходная папка.
